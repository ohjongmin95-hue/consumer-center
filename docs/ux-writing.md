# 소비자제보센터 UX 라이팅 가이드

운영자가 2026-11-03에 준 토스 UX 라이팅 가이드를 제보센터 기준으로 정리했어요.
화면 문구, 알림, 오류 메시지, AI가 쓰는 문장 모두 이 기준을 따라요. 부연 설명을 늘리지 말고, 짧고 분명하게 써요.

## 1. 해요체
- 모든 문구는 해요체로 써요. `~합니다`, `~습니다`는 쓰지 않아요.
  - 보냅니다 → 보낼게요, 접수됐습니다 → 접수했어요
- 예외: 기업에 보내는 공문형 메일(입장 요청서 등), 법적 고지 원문, 카카오 알림톡처럼 미리 심사받은 템플릿은 그대로 둬요.

## 2. 능동형으로
- 사용자나 센터가 한 일은 능동형으로: 접수됐어요 → 접수했어요
- `~었` 빼기: 바뀌었어요 → 바꿨어요
- 동사 바꿔쓰기: 높아졌어요 → 올랐어요
- 수동형이 더 나은 경우
  - 서비스 종료, 기간 만료처럼 주어(서비스, 기간)를 강조할 때: '종료돼요', '만료돼요'
  - 사용자 행동 때문에 생기는 결과를 알릴 때(연체, 해지, 적용 등)
  - 정보 수집 안내처럼 사용자를 안심시킬 때
- `되어요`는 쓰지 않고 `돼요`로 통일해요.

## 3. 긍정적으로
- 없어요·안 돼요 → ~하면 할 수 있어요
  - 로그인하기 전에는 제보할 수 없어요 → 로그인하면 제보할 수 있어요
- 오류 메시지는 무엇을 하면 되는지 알려 줘요.
  - 지금은 쓸 수 없어요 → 앱을 업데이트해 주세요
- 부정형이 맞는 경우: 정책상 쓸 수 없을 때(이유를 함께), 일부 기능만 쓸 수 없을 때, 사용자를 안심시킬 때(예: 연락처는 공개하지 않아요)

## 4. 캐주얼한 경어
- `~시겠어요?`, `~시나요?`, `~께`, `계시다`, `여쭤보다` 같은 과한 경어를 쓰지 않아요.
  - 해지하시겠어요? → 해지할까요?
  - 시작하시는 분에게 → 시작하면
  - 가지고 계시나요? → 있나요?
  - 여쭤볼게요 → 확인할게요
  - 께 → 에게
- 경어를 빼서 어색하면, 알고 싶은 정보를 주어로 써요.
  - 어떤 목적으로 대출받으시나요? → 대출 목적이 무엇인가요?
  - 어떤 이유로 신고하시나요? → 신고 이유를 골라 주세요
- 경어를 써도 되는 경우: 사용자의 맥락을 물을 때(어떤 일을 겪으셨나요?), 사용자의 상황을 추정해 직접 판단하게 할 때, 설문처럼 선의가 필요할 때

## 5. 명사+명사 쓰지 않기
- 한자어 명사를 풀어서 동사로 써요.
  - 잔액 부족으로 → 잔액이 부족해서
  - 제보 접수 완료 → 제보를 접수했어요

## 제보센터에서 자주 쓰는 표현
- 제보가 접수됐습니다 → 제보를 접수했어요
- 표시할 제보 내역이 없습니다 → 아직 올라온 제보가 없어요. 첫 제보를 남겨 주세요.
- 검색 조건에 맞는 제보 내역이 없습니다 → 찾는 제보가 없어요. 다른 낱말로 찾아보세요.
- 로그인에 실패했습니다 → 로그인하지 못했어요. 비밀번호를 다시 확인해 주세요.
