# 소비자제보센터 앞으로 할 일 (아이디어 메모)

2026년 10월에 정리한 방향과 기능 아이디어입니다. 아직 시작하지 않았고, 시작할 때 이 문서를 기준으로 진행합니다.

## 방향
"제보를 받는 창구"를 넘어 **기업이 답하고, 해결이 기록되는 소비자 플랫폼**으로 간다. (참고 모델: 브라질 Reclame Aqui)

순환 구조: 소비자 제보 → 기업 답변 → 소비자가 해결 여부 평가 → 업체별 평판 점수 → 검색으로 새 소비자 유입 → 기업도 답할 수밖에 없음

## A. 기업이 직접 답변하는 구조 (운영자가 전달하지 않아도 되게)
지금은 제보마다 관리자 화면에서 1회용 링크를 만들어 기업에 직접 보내야 함 (`/admin/invite`, `/company/<id>/<token>`).

1. **기업 회원**: 회사명, 사업자등록번호, 담당자, 회사 이메일로 가입
   - 국세청 사업자등록 진위확인 API(공공데이터포털, 무료)로 자동 확인
   - 회사 이메일 인증 코드
   - 운영자가 관리자 화면에서 최종 승인 1회 (사칭 방지)
   - 회사의 여러 이름(OO쇼핑, OO몰 등)을 함께 연결
2. **자동 알림**: 제보자가 "기업 전달"에 동의한 제보만 해당 기업에 노출, 담당자에게 새 제보 메일 자동 발송. 연락처·첨부파일은 계속 비공개
3. **기업 전용 화면**: 우리 회사 제보 목록(미답변/답변 완료), 바로 답변, 담당자 여러 명
4. **즉시 전달**: 답변하면 제보자 진행 화면·내 정보에 바로 표시, 이메일 있으면 "기업이 답변했어요" 메일, 단계 자동 변경(기업 답변 대기 → 조정 진행), 공개 제보에는 기업 답변도 공개
5. **미가입 기업**: 관리자가 업체 고객센터 이메일을 한 번 등록해 두면 제보가 올 때마다 답변 초대 메일 자동 발송

준비물: 메일 발송 서비스(네이버 클라우드 Cloud Outbound Mailer 추천, 처음엔 개인 메일 SMTP도 가능), 공공데이터포털 API 키, 기업 회원 약관·개인정보 처리방침(제3자 제공) 보완

만드는 순서: ① 기업 가입·승인·답변 화면·즉시 표시 → ② 메일 알림 → ③ 사업자번호 자동 확인·초대 메일·공개 답변 표시

## B. 플랫폼 기능
**1단계 (뼈대)**
- 업체 페이지: 제보 수, 기업 답변률, 해결률, 평균 답변 시간, 피해 유형 분포 ("업체명 + 환불" 검색 유입 입구)
- 해결 평가: 기업 답변 후 제보자가 "해결됐어요/아직이에요"와 만족도 → 업체 점수
- "나도 겪었어요" 버튼: 같은 피해가 쌓이면 집단 피해 표시, 한국소비자원 집단분쟁조정 안내
- 구매 인증 배지: 영수증·주문 내역 확인된 제보 표시

**2단계 (재방문 이유)**
- 도구: 환불 가능 기간 계산기(청약철회 7일 등), 중도해지 위약금 계산기, 환불 요청서·내용증명 양식 작성기 (법률 자문이 아니라 양식 채우기까지만)
- 알림: 단계 변경·기업 답변 시 이메일/카카오 알림톡
- 피해 유형별 해결 가이드

**3단계 (수익)**
- 기업용 유료 관리 화면: 답변 관리, 통계, 담당자 계정, 응답 우수 기업 배지
  - 원칙: **돈을 받고 제보를 지워 주지 않는다** (약관에 공개)
- 업종별 피해 동향 데이터 리포트

## C. 마케팅
- 검색 유입 최우선: 업체 페이지와 가이드가 "업체명 + 환불/해지/고객센터"에 노출되게. 네이버 블로그·카페 꾸준히
- 대형 피해 이슈 발생 시 하루 안에 특별 접수 페이지 → 언론 인용
- 월간 소비자 피해 리포트를 기자들에게 배포
- 해결 사례 카드 이미지로 SNS 공유 유도
- 카카오톡 채널로 피해 예방 소식·사기 주의보

## D. 꼭 챙길 위험
- 명예훼손: 업체 점수는 숫자(답변률·해결률)로만, 기업 반론 기회 보장, 임시조치 절차 유지
- 변호사법: 도구는 양식 채우기까지만
- 허위 제보: 구매 인증과 신고 처리 기록으로 관리

## 그 밖에 미뤄 둔 것
- 앱: 먼저 홈 화면 앱(PWA), 필요하면 안드로이드 플레이스토어, 아이폰은 푸시 알림 붙일 때
- 비밀번호 자동 찾기(메일 발송 필요), 네이버·카카오 간편로그인
- 작업 브랜치를 기본 브랜치(main)에 합치기 (새 서버 설치 시 최신 코드가 깔리도록)
