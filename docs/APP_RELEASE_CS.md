# 소보루 CS 사장님 앱: 구글 플레이 출시 안내

`mobile/` 폴더의 Expo 앱입니다. 앱 이름 `소보루 CS`, 패키지 이름 `kr.co.soboru.cs`, EAS 프로젝트는 이미 연결돼 있어요.
(`docs/APP_RELEASE.md`는 소비자제보센터 웹앱 이야기라 이 앱과 다릅니다.)

## 1. Play Console 계정

- play.google.com/console 에서 **조직 계정**으로 만드세요 (등록비 25달러, 한 번만 내요). 사업자 정보와 **D-U-N-S 번호**가 필요해요. 없으면 dnb.com에서 무료로 신청해요.
- **개인 계정**은 2023년 11월 뒤에 만들었으면 정식 출시 전에 **테스터 12명이 14일 동안** 비공개 테스트를 해야 해요. 조직 계정은 이 조건이 없어요.
- 계정 만들 때 개발자 연락처 전화·이메일·주소를 넣어요. 연락처 이메일은 스토어에 공개돼요.

## 2. 업로드 파일(.aab) 만들기 (내 컴퓨터, 한 번에 10~20분)

Node.js 20 이상이 있는 컴퓨터에서:

```bash
git clone https://github.com/ohjongmin95-hue/consumer-center.git   # 이미 있으면 git pull
cd consumer-center/mobile
npm ci
npx eas-cli@latest login                     # Expo 계정
npx eas-cli@latest build -p android --profile production
```

- 처음이면 **"Generate a new Android Keystore?" → Yes**. 서명 키는 Expo 서버에 안전하게 보관돼요.
- 알림(푸시)을 쓰려면 Firebase의 `google-services.json`이 필요해요. EAS 웹(expo.dev > 프로젝트 > Environment variables)에 **파일 변수 `GOOGLE_SERVICES_JSON`**(production 환경)으로 올려 두면 빌드에 자동으로 들어가요. 없으면 앱은 되지만 푸시 알림이 안 와요.
- 끝나면 터미널에 나오는 링크에서 **`.aab` 파일**을 내려받아요.
- 버전 번호(versionCode)는 EAS가 빌드할 때마다 알아서 올려요.

## 3. Play Console에 올리기

1. **앱 만들기**: 앱 이름 `소보루 CS`, 기본 언어 한국어, 앱, 무료.
2. **테스트 > 내부 테스트 > 새 버전 만들기**: `.aab` 업로드. **Play 앱 서명**은 기본값(사용) 그대로.
3. 테스터에 내 구글 계정을 넣고, 나오는 링크로 휴대폰에 설치해 확인해요.
4. 아래 **앱 콘텐츠**와 **스토어 등록정보**를 채운 뒤 **프로덕션**으로 출시해요 (개인 계정이면 그 전에 비공개 테스트 14일).

### 데이터 보안 양식

- 데이터 수집: **예** / 제3자와 공유: **아니요** (서버·AI 처리 업체는 위탁이라 '공유'가 아니에요)
- 전송 중 암호화: **예** / 삭제 요청 방법 제공: **예**

| 데이터 유형 | 수집 | 목적 | 필수 |
|---|---|---|---|
| 개인 정보 > 이름 | 예 | 앱 기능, 계정 관리 | 필수 |
| 개인 정보 > 이메일 주소 | 예 | 앱 기능, 계정 관리 | 필수 |
| 개인 정보 > 전화번호 | 예 | 앱 기능, 계정 관리 | 필수 |
| 메시지 > 기타 인앱 메시지 | 예 (고객 문의와 답변) | 앱 기능 | 필수 |

```

■ 요청을 한곳에서

■ 자동 처리
배송 조회처럼 자주 오는 문의는 미리 정한 규칙과 답변 템플릿으로 자동으로 답해요.

새 요청과 답변 기한을 알림으로 받고, 요청 유형과 처리 시간을 통계로 확인해요.

■ 팀으로
직원 계정을 만들어 요청을 나눠 맡기고 내부 메모로 의견을 나눠요.

※ 사업자 회원 전용 앱이에요. biz.soboru.co.kr 에서 무료로 가입할 수 있어요.
```
