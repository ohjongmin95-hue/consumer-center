# 제보자 알림 (카카오 알림톡 · 이메일)

제보자에게 아래 세 순간에 자동으로 알림을 보냅니다.

| 언제 | 카카오톡 템플릿 설정 이름 |
|---|---|
| 제보가 접수됐을 때 | `KAKAO_TPL_RECEIVED` |
| 관리자가 진행 단계를 바꿨을 때 | `KAKAO_TPL_STATUS` |
| 센터가 제보자에게 메시지를 보냈을 때 | `KAKAO_TPL_MESSAGE` |

- 카카오톡은 제보 때 적은 **휴대폰 번호(010…)**로, 이메일은 **이메일을 적은 사람에게만** 갑니다.
- 메시지 본문에는 센터 답변 내용을 넣지 않고 "내 제보 조회에서 확인해 주세요"라고만 안내합니다(개인정보 보호).
- 서버 설정 파일(`/etc/soboru.env`)에 값을 넣어야 켜집니다. 값을 비우면 그 알림만 꺼집니다.
- 보낸 결과(성공·실패)는 관리자 제보 상세 화면의 **제보자 알림** 칸에 남습니다.

## 1. 이메일 켜기

지메일 예시 (네이버도 비슷: `smtp.naver.com`, 네이버 메일 환경설정에서 IMAP/SMTP 사용 켜기)

1. 구글 계정 → 보안 → 2단계 인증 켜기 → **앱 비밀번호** 만들기(16자리)
2. 서버에서 `sudo nano /etc/soboru.env` 열고 맨 아래에 추가

   ```
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=465
   SMTP_USER=보내는주소@gmail.com
   SMTP_PASSWORD=앱비밀번호16자리
   MAIL_FROM_NAME=소비자제보센터
   ```
3. `sudo systemctl restart soboru`

## 2. 카카오 알림톡 켜기 (솔라피)

1. **카카오톡 채널** 만들기: [카카오톡 채널 관리자센터](https://center-pf.kakao.com)에서 채널 개설 → 비즈니스 인증(사업자등록증)
2. **솔라피 가입**: [solapi.com](https://solapi.com) → 충전(선불)
3. 솔라피 콘솔 → 카카오 → **채널 연동**: 위에서 만든 채널 검색·연동 → 표시되는 **pfId** 복사
4. 솔라피 콘솔 → 카카오 → **알림톡 템플릿 등록**: 아래 3개를 **글자 하나까지 그대로** 등록하고 심사 요청(보통 1~3영업일)
5. 심사가 통과하면 각 템플릿의 **템플릿 ID**를 복사
6. 솔라피 콘솔 → 개발/연동 → **API Key 발급** (API Key, API Secret)
7. 서버 `/etc/soboru.env`에 추가하고 `sudo systemctl restart soboru`

   ```
   SOLAPI_API_KEY=발급받은키
   SOLAPI_API_SECRET=발급받은시크릿
   SOLAPI_PFID=채널pfId
   KAKAO_TPL_RECEIVED=접수템플릿ID
   KAKAO_TPL_STATUS=단계변경템플릿ID
   KAKAO_TPL_MESSAGE=답변템플릿ID
   ```

### 등록할 알림톡 템플릿

공통: 메시지 유형 **기본형**, 카테고리 **서비스 이용 > 이용안내/공지** (솔라피 화면 이름 기준, 비슷한 항목 선택).
버튼은 세 템플릿 모두 **웹링크** 1개: 버튼 이름 `진행 상황 보기`, 모바일·PC 링크 `https://consumerjebo.co.kr/lookup`

**① 제보 접수 (`KAKAO_TPL_RECEIVED`)**

```
[소비자제보센터] 제보 접수 안내

#{이름}님, 제보가 접수됐습니다.

■ 접수번호: #{접수번호}
■ 제목: #{제목}

진행 상황은 소비자제보센터 '내 제보 조회'에서 휴대폰 번호와 조회 비밀번호로 확인할 수 있습니다.
```

**② 진행 단계 변경 (`KAKAO_TPL_STATUS`)**

```
[소비자제보센터] 진행 상황 안내

#{이름}님의 제보 진행 단계가 바뀌었습니다.

■ 접수번호: #{접수번호}
■ 제목: #{제목}
■ 현재 단계: #{단계}

자세한 내용은 소비자제보센터 '내 제보 조회'에서 확인해 주세요.
```

**③ 센터 답변 (`KAKAO_TPL_MESSAGE`)**

```
[소비자제보센터] 답변 등록 안내

#{이름}님의 제보에 센터 답변이 등록됐습니다.

■ 접수번호: #{접수번호}
■ 제목: #{제목}

답변 내용은 소비자제보센터 '내 제보 조회'에서 확인해 주세요.
```

변수 이름(`#{이름}`, `#{접수번호}`, `#{제목}`, `#{단계}`)은 코드와 맞춰져 있으니 바꾸지 마세요. 문구를 바꾸고 싶으면 다시 심사를 받아야 하고, 이메일 문구(`notify.py`의 `EMAIL_TEXT`)도 함께 맞춰 주세요.

## 3. 개인정보 처리방침에 추가할 내용

발송 업체에 휴대폰 번호·이메일이 넘어가므로 **처리 위탁**에 추가해야 합니다. 관리자 → 약관 편집 → 개인정보 처리방침 "6. 개인정보 처리의 위탁"에 실제 쓰는 업체로 적어 주세요.

```
- 수탁자: 주식회사 솔라피
- 위탁 업무: 카카오 알림톡 발송
- 수탁자: (이메일 발송 업체, 예: Google LLC)
- 위탁 업무: 이메일 발송
```

지메일처럼 해외 업체를 쓰면 "개인정보는 국외로 이전되지 않습니다" 문장도 고쳐야 합니다(국외 이전 항목 추가). 네이버 메일·국내 업체를 쓰면 그대로 둬도 됩니다.
