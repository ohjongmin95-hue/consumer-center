# 제보자 알림 (카카오 알림톡 · 이메일)

제보자에게 아래 순간에 자동으로 알림을 보냅니다.

| 언제 | 카카오톡 템플릿 설정 이름 |
|---|---|
| 제보가 접수됐을 때 | `KAKAO_TPL_RECEIVED` |
| 관리자가 진행 단계를 바꿨을 때 | `KAKAO_TPL_STATUS` |
| 센터가 제보자에게 메시지를 보냈을 때 | `KAKAO_TPL_MESSAGE` |
| 기업이 제보에 답변했을 때 | `KAKAO_TPL_COMPANY` |
| 센터가 보완을 요청했을 때 | `KAKAO_TPL_SUPPLEMENT` |
| 기업이 답변 링크를 열어 봤을 때 | `KAKAO_TPL_SEEN` |

- 카카오톡은 제보 때 적은 **휴대폰 번호(010…)**로, 이메일은 **이메일을 적은 사람에게만** 갑니다.
- 메시지 본문에는 센터 답변 내용을 넣지 않고 "내 제보 조회에서 확인해 주세요"라고만 안내합니다(개인정보 보호).
- 서버 설정 파일(`/etc/soboru.env`)에 값을 넣어야 켜집니다. 값을 비우면 그 알림만 꺼집니다.
- 보낸 결과(성공·실패)는 관리자 제보 상세 화면의 **제보자 알림** 칸에 남습니다.

## 1. 이메일 켜기

지메일 예시 (네이버도 비슷: `smtp.naver.com`, 네이버 메일 환경설정에서 IMAP/SMTP 사용 켜기)

1. 구글 계정 → 보안 → 2단계 인증 켜기 → **앱 비밀번호** 만들기(16자리)
2. 서버에서 `sudo nano /etc/soboru.env` 열고 맨 아래에 추가

   ```
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=465
   SMTP_USER=보내는주소@gmail.com
   SMTP_PASSWORD=앱비밀번호16자리
   MAIL_FROM_NAME=소비자제보센터
   ```
3. `sudo systemctl restart soboru`

## 2. 카카오 알림톡 켜기 (솔라피)

솔라피는 카카오 알림톡을 대신 보내 주는 업체예요. 카카오톡 채널을 만들고, 솔라피에 그 채널을 연결해 템플릿 심사를 받으면 돼요. 보낸 만큼만 선불 충전금에서 빠져요(요금은 솔라피 요금표 확인).

1. **카카오톡 채널** 만들기: [카카오톡 채널 관리자센터](https://center-pf.kakao.com)에서 채널 개설(이름 예: 소보루) → 비즈니스 인증(사업자등록증)
2. **솔라피 가입**: [solapi.com](https://solapi.com) → 사업자 인증 → 충전(선불)
3. 솔라피 콘솔 → 카카오 → **채널 연동**: 1에서 만든 채널을 연동하고 **pfId**(KA01PF…) 확인
4. 솔라피 콘솔 → 카카오 → **알림톡 템플릿 등록**: 아래 6개를 **글자 하나까지 그대로** 등록하고 심사 요청(보통 1~3영업일)
5. 솔라피 콘솔 → 개발/연동 → **API Key 발급** (API Key, API Secret)
6. 서버에서 `sudo bash /opt/soboru/app/deploy/set-kakao.sh` 실행 → 묻는 대로 키·pfId·템플릿 ID 입력
   - 키·시크릿은 화면에 안 보이게 입력돼요. 템플릿 심사가 나중에 끝나면 다시 실행해서 그 ID만 넣으면 돼요(빈칸은 지금 값 유지).
   - 템플릿 ID를 넣은 알림부터 켜져요. 소보루와 소비자제보센터 제보 모두 같은 채널로 가요.

### 등록할 알림톡 템플릿

공통: 메시지 유형 **기본형**, 카테고리 **서비스 이용 > 이용안내/공지** (솔라피 화면 이름 기준, 비슷한 항목 선택).
버튼은 모두 **웹링크** 1개: 버튼 이름 `진행 상황 보기`, 모바일·PC 링크 `https://soboru.co.kr/lookup`

**① 제보 접수 (`KAKAO_TPL_RECEIVED`)**

```
[소보루] 제보 접수 안내

#{이름}님, 제보가 접수됐습니다.

■ 접수번호: #{접수번호}
■ 제목: #{제목}

진행 상황은 '내 제보 조회'에서 휴대폰 번호와 조회 비밀번호로 확인할 수 있습니다.
```

**② 진행 단계 변경 (`KAKAO_TPL_STATUS`)**

```
[소보루] 진행 상황 안내

#{이름}님의 제보 진행 단계가 바뀌었습니다.

■ 접수번호: #{접수번호}
■ 제목: #{제목}
■ 현재 단계: #{단계}

자세한 내용은 '내 제보 조회'에서 확인해 주세요.
```

**③ 센터 답변 (`KAKAO_TPL_MESSAGE`)**

```
[소보루] 답변 등록 안내

#{이름}님의 제보에 센터 답변이 등록됐습니다.

■ 접수번호: #{접수번호}
■ 제목: #{제목}

답변 내용은 '내 제보 조회'에서 확인해 주세요.
```

**④ 기업 답변 (`KAKAO_TPL_COMPANY`)**

```
[소보루] 업체 답변 안내

#{이름}님의 제보에 업체가 답변했습니다.

■ 접수번호: #{접수번호}
■ 제목: #{제목}

답변 내용은 '내 제보 조회'에서 확인해 주세요. 답변을 받고 해결됐는지도 알려 주세요.
```

**⑤ 보완 요청 (`KAKAO_TPL_SUPPLEMENT`)**

```
[소보루] 제보 보완 요청

#{이름}님의 제보를 확인하려면 내용이나 자료 보완이 필요합니다.

■ 접수번호: #{접수번호}
■ 제목: #{제목}

요청 내용은 '내 제보 조회'에서 확인하고, 그 화면에서 설명이나 자료를 더해 주세요.
```

**⑥ 기업 확인 (`KAKAO_TPL_SEEN`)**

```
[소보루] 업체 확인 안내

#{이름}님의 제보를 업체 담당자가 열어 확인했습니다.

■ 접수번호: #{접수번호}
■ 제목: #{제목}

업체가 답변하면 다시 알려 드립니다. 답변 여부와 내용은 업체가 정합니다.
```

변수 이름(`#{이름}`, `#{접수번호}`, `#{제목}`, `#{단계}`)은 코드와 맞춰져 있으니 바꾸지 마세요. 문구를 바꾸려면 다시 심사를 받아야 해요.

## 3. 개인정보 처리방침에 추가할 내용

발송 업체에 휴대폰 번호·이메일이 넘어가므로 **처리 위탁**에 추가해야 합니다. 관리자 → 약관 편집 → 개인정보 처리방침 "6. 개인정보 처리의 위탁"에 실제 쓰는 업체로 적어 주세요.

```
- 수탁자: 주식회사 솔라피
- 위탁 업무: 카카오 알림톡 발송
- 수탁자: (이메일 발송 업체, 예: Google LLC)
- 위탁 업무: 이메일 발송
```

지메일처럼 해외 업체를 쓰면 "개인정보는 국외로 이전되지 않습니다" 문장도 고쳐야 합니다(국외 이전 항목 추가). 네이버 메일·국내 업체를 쓰면 그대로 둬도 됩니다.

## 3. 새 제보 운영자 알림

새 제보가 들어오면 운영자에게 바로 알려 줍니다. 접수번호, 제보자 이름과 연락처, 업체, 제목을 보냅니다.

- **받는 번호 바꾸기**: `sudo bash /opt/soboru/app/deploy/set-alert.sh 010-0000-0000` (쉼표로 여러 번호 가능)
- **카카오톡**: `/etc/soboru.env`에 아래를 넣으면 켜집니다. 위 2번(솔라피·채널 연동)이 먼저 되어 있어야 합니다.
  ```
  ADMIN_ALERT_PHONE=010xxxxxxxx
  KAKAO_TPL_ADMIN=운영자알림템플릿ID
  SOLAPI_SENDER=솔라피에등록한발신번호
  ```
  `SOLAPI_SENDER`가 있으면 알림톡이 실패하거나 템플릿 심사 전일 때 같은 내용이 문자로 갑니다. 템플릿 없이 `SOLAPI_SENDER`만 있으면 문자로만 갑니다.

  운영자 알림 템플릿(글자 하나까지 그대로 등록):
  ```
  [소비자제보센터] 새 제보가 접수됐습니다.

  ■ 접수번호: #{접수번호}
  ■ 제보자: #{이름} (#{연락처})
  ■ 업체: #{업체}
  ■ 제목: #{제목}

  관리자 화면에서 확인해 주세요.
  ```
- **텔레그램 (무료, 추천)**: 텔레그램에서 @BotFather 에게 `/newbot`을 보내 봇을 만들고 토큰을 받습니다. 운영자들이 있는 단톡방에 봇을 초대하고 아무 말이나 한 번 보낸 뒤, 서버에서 `sudo bash /opt/soboru/app/deploy/set-telegram.sh '봇토큰'`을 실행하면 단톡방을 찾아 연결합니다.
- **메일 (무료)**: `sudo bash /opt/soboru/app/deploy/set-mail.sh 보내는주소@gmail.com '앱비밀번호' 받을주소1,받을주소2` 한 줄로 켭니다. 휴대폰 메일 앱(지메일·네이버 메일) 알림을 켜 두면 휴대폰으로 바로 알 수 있습니다.
- **관리자 화면**: 설정 없이도 관리자 화면을 켜 두면 30초마다 확인해서 메뉴에 숫자, 화면 아래 알림을 띄웁니다. 관리자 홈의 "브라우저 알림 켜기"를 누르면 다른 창을 보고 있어도 컴퓨터 알림이 뜹니다.
