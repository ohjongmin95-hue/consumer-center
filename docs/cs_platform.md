# SOBORU CS 운영 플랫폼 구축 계획

> **"소비자 민원은 한큐에, 기업의 CS 운영도 한큐에."**
> 소비자에게는 통합 민원 접수·처리 창구를, 기업에는 자동화와 의사결정 기능을 제공하는 양면형 CS 운영 플랫폼.

2026년 10월 사업 방향 정리를 바탕으로 했습니다. 'CS 대행 서비스'가 아니라 **'CS 운영 플랫폼'**을 전면에 내세웁니다.

## 왜 필요한가

채널톡 같은 기업용 상담 솔루션은 이미 있다. 부족한 건 **소비자와 여러 중소기업을 하나로 연결하면서, 실제 민원 처리까지 수행하는 플랫폼**이다. SOBORU는 CS 인력 대행과 기업용 상담 솔루션 사이의 빈틈을 노린다.

경쟁력은 상담 인력 수가 아니라, **한 건의 민원을 소비자 접수부터 기업의 실제 조치까지 얼마나 적은 사람의 개입으로 끝내느냐**에 있다.

## 구조

| | 소비자제보센터 | SOBORU Business |
|---|---|---|
| 한 줄 | 민원 접수 한큐에 | CS 운영 한큐에 |
| 누가 | 소비자 | 중소기업 (대표·담당자) |
| 하는 일 | 어느 기업이든 한곳에서 접수·조회 | 문의 현황 확인, 필요한 건만 승인, 반복 업무 자동화 |
| 얻는 가치 | 접수부터 결과 확인까지 한곳에서 | 직원 없이도 CS가 돌아가고, 대표는 중요한 결정만 |

**SOBORU Platform**: 두 서비스가 하나의 사건을 같은 시스템에서 처리한다.
분류 → 전달 → 응답 → 승인 → 업무 실행 → 결과 확인

## 처리 흐름 (예: "A화장품 제품 불량인데 교환을 못 받았어요")

1. 소비자제보센터가 민원을 접수하고 증빙을 정리
2. SOBORU Business가 A화장품에 사건을 전달
3. 자동 처리 기준에 해당하면 프로그램이 후속 업무 실행 (예: 교환 접수 안내 답변 + 회수 요청)
4. 예외 사건이면 A화장품 대표에게 승인 요청 (요약 + 추천 조치 → 승인·보류·추가 확인)
5. 소비자는 처리 상태와 결과를 한 화면에서 확인

## 입점 기업과 비입점 기업의 처리 수준

신뢰를 위해 화면과 안내에서 분명히 나눈다.

| | 입점 기업 (SOBORU Business) | 비입점 기업 |
|---|---|---|
| 전달 | 기업 화면으로 바로 전달 | 소비자 동의에 따라 공식 연락처로 전달 시도 |
| 답변 | 기업이 직접 답변, 소비자에게 바로 표시 | 회신이 오면 센터가 기록 |
| 자동 처리·승인 | 가능 (기업이 정한 규칙) | 불가 |
| 소비자 안내 | 처리 단계·답변 목표일 표시 | 공식 연락처 안내, 회신 추적, 미해결 시 피해구제 절차 안내 |

## 차별화 포인트 → 기능

1. **여러 기업을 연결하는 공동 플랫폼**: 소비자는 한 곳에서 여러 기업 민원을 접수·조회. 기업별 전용 문의 페이지도 제공.
2. **대표의 원클릭 의사결정**: 불만 요약 + 추천 조치 → 승인·보류·추가 확인. 승인하면 미리 정한 후속 절차가 실행.
3. **반복 민원 자동 처리**: 배송 조회, 교환 접수, 반품 회수처럼 정형화된 업무는 기업이 승인한 규칙과 외부 시스템 연동으로 처리.
4. **미해결 민원 지속 관리**: 답변이 없으면 후속 확인, 필요하면 공식 소비자상담·피해구제 절차 안내.

## 단계별 구축

### 1단계: SOBORU Business 기본 (지금 만드는 것)
- 기업 전용 문의 페이지(`/cs/회사주소`)와 '문의하기' 버튼 코드
- 기업 '고객 문의' 화면: 답변 대기 / 답변 완료 / 종결, 답변 목표일 지난 문의 표시
- 소비자: 휴대폰 번호 + 조회 비밀번호로 문의 확인, 추가 문의, '해결됐어요 / 아직이에요' 평가
- 답변 목표일이 지나도 답이 없거나 해결이 안 되면 소비자가 원할 때 소비자제보센터 제보로 넘기기
- 새 문의·답변 이메일 알림
- 기존 기능 연결: 소비자제보센터 제보 중 기업 전달에 동의한 것은 이미 입점 기업 화면으로 전달되고 기업이 답변함

### 2단계: 대표 원클릭 의사결정
- 사건마다 요약과 추천 조치 카드 (처음엔 유형별 기본 추천, 3단계에서 AI)
- 승인 / 보류 / 추가 확인 버튼. 승인하면 미리 정한 답변·후속 절차 실행, 추가 확인은 소비자에게 자료 요청
- 대표 휴대폰으로 승인 요청 알림 (카카오 알림톡)
- 담당자 여러 명, 담당자 배정, 자주 쓰는 답변

### 3단계: 반복 민원 자동 처리
- 기업별 자동 처리 규칙: "유형이 배송 조회면 → 송장 조회 결과로 자동 답변" 등
- 외부 연동: 택배 송장 조회 API, 스마트스토어·카페24 주문 연동, 반품 회수 요청
- AI 분류·요약·답변 초안 (Claude API, 사용량만큼 비용)
- 처리 통계: 유형별 건수, 평균 처리 시간, 자동 처리율, 해결률

### 4단계: 비입점 기업 처리와 피해구제 지원
- 비입점 기업 공식 연락처 DB, 소비자 동의 시 민원 전달 시도와 회신 추적
- 미해결 사안의 소비자상담(1372)·피해구제·분쟁조정 절차 안내, 증빙 정리
- 내 증빙 보관함, 진행 일정 관리
- 업체별 공개 페이지와 해결률 배지

## 운영 원칙

- **소비자 권익 보호**: 기업의 유료 서비스 이용 여부가 제보 처리, 공개 판단, 소비자 권리에 영향을 주지 않는다.
- **언론 독립**: SOBORU 언론사는 공익적인 소비자 문제를 독립적으로 취재·보도한다. 소비자제보센터와 SOBORU Business는 민원 접수·처리 플랫폼이다. 기업이 플랫폼 이용료를 낸다고 보도 여부나 내용이 바뀌지 않는다. 기업이 맡긴 문의 내용은 취재에 쓰지 않는다.
- **기업 답변의 자율성**: 기업의 답변이나 원하는 결과를 보장하지 않으며, 실제 전달·답변 상태를 구분해 표시한다.
- **법률 업무 구분**: 절차 안내와 자료 정리 중심. 법률사건 대리·협상은 하지 않는다.
- **개인정보 보호**: 증빙·연락처 접근 권한, 보관 기간, 제공 동의 체계를 갖춘다.

## 코드 밖에서 준비할 것

- **개인정보 처리방침·기업 이용약관 개정**: 기업 문의함에서 센터가 처리 위탁(수탁자)인지 제3자 제공인지, 보관 기간, 유료 조건. 법률 검토 필요.
- **메일 발송 계정 (SMTP)**: 문의 알림에 필요.
- **카카오 알림톡 템플릿 추가**: 문의 접수·답변·대표 승인 요청.
- **외부 연동 계약·키**: 택배 조회 API, 쇼핑몰 플랫폼 API (3단계).
- **유료화 시 결제**: 정기결제, 세금계산서.
- **서버 백업**: DB와 첨부 폴더 정기 백업.
- **검증**: 스마트스토어·쿠팡 판매자 몇 곳을 무료로 받아 실제로 쓰는지 확인.
