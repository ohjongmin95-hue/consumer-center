# SOBORU 플랫폼 (한큐 + 소보루 비즈)

소비자제보센터 홈페이지와 분리된 별도 서비스예요. 같은 서버, 같은 저장소를 쓰지만 DB·주소·서비스가 따로예요.

| 주소 | 서비스 | 누가 |
|---|---|---|
| `hanq.consumerjebo.co.kr` | 한큐 | 소비자: 어느 기업이든 접수, 진행 확인, 해결 여부 응답 |
| `business.consumerjebo.co.kr` | 소보루 비즈 | 입점 기업: 홈(바로가기·승인 요청·최근 요청), 승인 요청, 전체 요청(검색), 자동 처리, 통계, 설정 |
| `business.consumerjebo.co.kr/ops` | 운영 | 센터: 기업 가입 승인, 비입점 기업 요청 처리 |

소비자 서비스 이름은 기본값 `한큐`이고, `/etc/soboru-platform.env`의 `CONSUMER_NAME`으로 바꿀 수 있어요.

코드: `platform_app/` (`hanq.py`가 실행 진입점, `core.py` 공통, `consumer.py` 소비자, `business.py` 기업·운영). 테스트: `tests/test_platform.py`.

## 처리 흐름

1. 소비자가 기업 → 유형 → 내용 → 원하는 해결 → 연락처 순서로 접수 (한 화면에 질문 하나)
2. **입점 기업 + 전달 동의**: 기업 화면으로 바로 전달, 답변 목표일 2일
   - 그 유형의 자동 처리를 켜 둔 기업이면 즉시 추천 조치 실행 + 답변
   - 아니면 승인 카드로 올라감: 승인(추천 조치 실행 + 답변) / 보류 / 자료 요청
3. **비입점 기업**: 운영 화면에서 공식 연락처로 전달 시도 기록 → 회신 기록 또는 회신 없음(피해구제 안내)
4. 소비자는 휴대폰 번호 + 조회 비밀번호로 어느 기기에서든 확인, 답변 후 해결됐어요 / 아직이에요
5. 미해결이거나 답변 목표일이 지나면 1372·한국소비자원 피해구제 안내

## 서버에 설치

1. 가비아 DNS에서 `hanq`, `business` 두 호스트를 consumerjebo.co.kr과 같은 서버 IP로 연결 (A 레코드)
2. 최신 코드 받기: `sudo bash /opt/soboru/app/deploy/update.sh` (main에 합쳐진 뒤)
3. 설치: `sudo bash /opt/soboru/app/deploy/platform-setup.sh hanq.consumerjebo.co.kr business.consumerjebo.co.kr 이메일`
   - 운영 화면 비밀번호를 물어봐요 (12자 이상)
   - DNS가 반영돼 있으면 HTTPS까지 자동 설정, 아니면 반영 뒤 같은 명령을 다시 실행
4. 설정 파일 `/etc/soboru-platform.env`: 메일 알림(SMTP), `PLATFORM_MODE=live`(시범 운영 띠 끄기)
5. 이후 업데이트는 기존과 같이 `update.sh` 한 번이면 두 서비스 모두 다시 시작돼요

## 기업 CS 도구

- **법 기준·응대 가이드**: 조문은 `platform_app/law_texts.json`에서만 보여 줘요. 국가법령정보센터 원문 미러(github.com/legalize-kr/legalize-kr)에서 `law_extract.py`로 글자 그대로 뽑은 것이라 손으로 고치지 않아요. 법이 바뀌면 원문을 다시 받아 스크립트를 돌려요. 품목별 소비자분쟁해결기준과 소비자기본법 시행령 별표 1은 원문을 담지 못해 공식 링크로만 안내해요.
- **답변 초안**: `ANTHROPIC_API_KEY`가 있으면 AI가 회사 말투로, 없으면 유형별 기본 문구로 초안을 만들어요 (`DRAFT_MODEL`로 모델 변경).
- **AI 상담창**: `ANTHROPIC_API_KEY`가 있으면 입점 기업 상담창에서 고객이 쓴 문장에 AI가 그 회사의 안내 문구·자동 처리 규칙·반품 안내·상품정보만 보고 답해요. 키가 없거나 실패하면 예전처럼 유형별 안내 문구로 답해요 (`CHAT_MODEL`로 모델 변경).
- **상품정보**: 자동 처리 화면 아래(앱은 더보기 > 상품정보)에서 상품 이름·가격·재고·안내를 등록해요. 엑셀에서 CSV로 저장한 목록을 한꺼번에 올릴 수도 있어요 (첫 줄: 상품명, 가격, 재고, 안내).
- **택배 배송 추적 (스마트택배)**: `SWEETTRACKER_TIER`, `SWEETTRACKER_KEY`가 있으면 송장을 스마트택배에 등록하고, 배송 상태가 바뀔 때마다 `/hook/trace/<서명 토큰>`으로 알림을 받아 요청 기록에 남기고 고객에게 알려요(배송 출발·배송 완료). 반품 상품이 배송 완료되면 기업에 메일로 알려요. 배송 조회 요청에는 기업이 '송장번호로 답하기'로 바로 답할 수 있어요. 지원 택배사: 우체국·CJ대한통운·한진·로젠·롯데. 키가 없으면 송장번호와 택배사 조회 링크만 보여요.
- **반품 안내·송장**: 설정의 반품 주소·택배사(소개만, 연동 없음)가 승인 답변 끝에 붙고, 소비자가 송장번호를 입력하면 기업이 회수 확인을 눌러요.
- **정기 알림** (`notify_late.py`, 한 시간마다): 답변 지연, 불량 조기 경보(같은 상품 7일 3건·같은 유형 7일 5건, 하루 한 번), 월간 CS 리포트(매달 1일).
- **카카오 알림톡**: 솔라피 키와 `BIZ_KAKAO_TPL_NEW`(카카오 심사를 받은 템플릿 ID)를 넣으면 알림톡을 켠 기업에 새 요청을 보내요. 템플릿 변수는 `#{회사}`, `#{유형}`, `#{요약}`, `#{링크}`예요. 템플릿 예:
  ```
  [소보루 비즈] #{회사}에 새 요청이 들어왔어요.
  ■ 유형: #{유형}
  ■ 요약: #{요약}
  눌러서 확인하고 승인해 주세요.
  #{링크}
  ```
- **소비자 알림톡**: `CS_KAKAO_TPL_REPLY`(심사받은 템플릿 ID)를 넣으면 기업 답변·자료 요청·회수 확인·새 상품 발송·환불 완료 때 접수한 휴대폰으로도 알려요 (이메일은 적었을 때만). 개인정보 처리방침의 위탁 업체에 이름이 나오도록 `KAKAO_VENDOR`에 발송 대행사 법인명을 넣어 주세요. 템플릿 변수는 `#{회사}`, `#{내용}`, `#{접수번호}`, `#{링크}`예요. 템플릿 예:
  ```
  [소보루 비즈 고객센터] #{회사}의 소식이 있어요.
  ■ 내용: #{내용}
  ■ 접수번호: #{접수번호}
  눌러서 확인해 주세요.
  #{링크}
  ```
- **비밀번호 찾기**: 소비자는 휴대폰 번호와 접수 때 적은 이메일로 30분짜리 바로 열기 링크를, 기업은 로그인 이메일로 1시간짜리 재설정 링크를 받아요. 메일(SMTP) 설정이 있어야 동작하고, 링크는 `SECRET_KEY`로 서명하므로 서버에 `SECRET_KEY`가 고정돼 있어야 해요.
- **업종 비교**: 같은 업종 다른 기업이 3곳 이상일 때만 평균을 보여 줘요.
- **법·제도 소식**: 운영 화면 `/ops/news`에서 출처 주소와 함께 직접 올려요 (자동 수집 없음).
