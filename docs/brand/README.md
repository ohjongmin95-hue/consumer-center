# SOBORU 브랜드 자료

## 소보루체

OH가 "소보루체로 해줘"라고 하면 아래 설정으로 글씨를 만든다.

- 글꼴: Pretendard ExtraBold (굵기 800). 파일: `docs/brand/Pretendard-ExtraBold.otf`
- 색: 진한 갈색 `#652D1C`
- 자간: -0.04em
- 처음 쓴 곳: 소보루 CS 공유 미리보기(`platform_app/static/og-biz.png`)의 "소보루 CS" 문구, 사이트 상단 로고 글자
- 웹에서는 `font-family: Pretendard; font-weight: 800; letter-spacing: -.04em; color: #652D1C;`
- Pretendard는 SIL Open Font License 1.1로 무료로 쓸 수 있다.
