# 민주의 카드뉴스 제작 프로그램

뉴스 링크나 기사 글을 넣으면 **SOBORU(소보루)** 인스타그램 카드뉴스를 만들어 주는 윈도우 프로그램입니다. 소보루 사이트와는 따로, 내 컴퓨터에서 돌아갑니다.

- 프로그램 화면은 토스처럼, 만드는 카드뉴스는 뉴닉 구성 + 소보루 색(귤색·크림·갈색)으로 만듭니다.

- 결과물: 표지 문구 후보 5개, 본문 3~4장, 마지막 장(행동 팁 3개 + 소보루 캐릭터), 이미지(힉스필드), 캡션(출처·해시태그 포함)
- 화면: 인스타처럼 카드를 옆으로 넘겨 보고, 글을 바로 고칠 수 있습니다.
- 내려받기: 버튼 하나로 카드 PNG(1080×1350, 4:5 세로)와 `caption.txt`를 zip 하나로 받습니다.
- 인스타그램에는 직접 올립니다. 자동 업로드 봇을 쓰면 계정 정지 위험이 있습니다.

## 처음 켜기 (윈도우)

1. 실행 파일을 받습니다.
   - GitHub 저장소 → 오른쪽 **Releases** → **민주의 카드뉴스 제작 프로그램 (최신)** → `MinjuCardNews-Setup.exe`(설치 파일)를 내려받아 실행하면 바탕화면·시작 메뉴에 **민주의 카드뉴스**가 생기고, 제거는 윈도우 "앱 및 기능"에서 해요. 설치 없이 쓰려면 `MinjuCardNews.exe`.
   - Python을 설치하지 않아도 됩니다. 바탕화면 같은 편한 곳에 두세요.
2. 바탕화면의 **민주의 카드뉴스**를 누릅니다. 끌 때는 [끄기]나 창의 ✕ → "종료할까요?"에서 [종료하기].
   - 처음에 "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 누릅니다. 서명하지 않은 새 프로그램이라 한 번 뜨는 창입니다.
   - 잠깐 뒤 프로그램 창이 열립니다.
3. **만들기** 화면에서 고릅니다.
   - **기사:** 뉴스 링크를 넣거나, 갖고 있는 기사 글을 그대로 붙여 넣습니다.
   - **글은 누가 쓸까요?**
     - **claude.ai에 붙여넣기 (추가 비용 없음):** 요청 글을 복사해서 claude.ai 채팅(구독)에 붙여 넣고, Claude 답을 다시 붙여 넣습니다.
     - **직접 쓰기 (비용 없음):** 빈 카드에 우리가 글을 씁니다.
     - **Claude 자동 (API 크레딧):** 링크만 넣으면 끝까지 자동으로 만듭니다. 설정에 Claude API 키가 있어야 합니다.
4. 카드 화면의 **이미지 (힉스필드)**에서 장마다 **사진**이나 **일러스트**를 고릅니다.
   - **① 설명 복사** → 힉스필드 사이트에 붙여 넣고 만들기 → **② 이미지 올리기** (프로그램 비용 없음)
   - 또는 힉스필드 API 키가 있으면 **힉스필드로 바로 만들기** (크레딧)
   - 이미지는 뉴닉처럼 카드 전체 배경으로 깔립니다.
5. 넘겨 보며 고치고, 체크리스트를 확인한 뒤 **PNG + 캡션 내려받기**를 누릅니다.

키는 꼭 넣지 않아도 됩니다. 자동으로 만들거나 힉스필드 사진을 바로 만들 때만 **설정**에서 넣습니다. 매일 자동 만들기는 Claude API 키가 있어야 합니다.

- 브라우저가 아니라 **프로그램 창**으로 열립니다. 윈도우에 들어 있는 Edge WebView2를 씁니다.
- 처음 켜면 **바탕화면에 바로가기**가 생깁니다. 다음부터는 그 아이콘을 누르면 됩니다.
- 끄기: 창을 닫거나, 화면 오른쪽 위의 **끄기**를 누릅니다.
- 예전 파일(`SoboruCardNews.exe`)이 "열려 있다"며 안 지워질 때가 있습니다. 브라우저에서 `127.0.0.1:5050`을 열고 **끄기**를 누르거나, 작업 관리자(Ctrl+Shift+Esc) → 세부 정보에서 작업을 끝낸 뒤 지웁니다.
- 이미 켜져 있을 때 exe를 또 누르면, 새로 켜지지 않고 브라우저만 다시 열립니다.
- 키, 설정, 만든 카드뉴스, 사진은 `문서\민주의 카드뉴스 제작 프로그램` 폴더에 저장됩니다. exe를 새 버전으로 바꿔도 그대로 남습니다.
- 여러 사람이 쓸 때는 각자 컴퓨터에서 exe를 켜고 각자 키를 넣습니다. 키가 저장된 `문서\민주의 카드뉴스 제작 프로그램` 폴더는 남에게 보내지 마세요.

## 설정

| 항목 | 설명 |
| --- | --- |
| Claude API 키 | 선택. '자동으로 만들기'와 '매일 자동'에만 씁니다. 없으면 claude.ai 붙여넣기나 직접 쓰기로 만듭니다. |
| 모델 | 기본은 Claude Opus 5.5입니다. Sonnet 5.5는 더 싸고 빠릅니다. |
| 힉스필드 (이미지) | 선택. 키(API Key, Secret)가 있으면 프로그램에서 바로 이미지를 만듭니다. '기본 이미지 스타일'(표지 사진+본문 일러스트 / 모두 사진 / 모두 일러스트)과 '새 카드뉴스 때 자동으로 만들기'를 고릅니다. 크레딧이 듭니다. |
| 네이버 키 | 같은 뉴스를 다룬 다른 언론사 기사를 찾아 사실을 맞춰 볼 때 먼저 씁니다. 매일 뉴스를 고를 때도 씁니다. 네이버 개발자센터 검색 API와 네이버 클라우드 API HUB 둘 다 됩니다. |
| Claude 웹 검색 | 네이버로 찾은 기사가 모자라면 Claude가 웹에서 더 찾습니다. 검색 1번에 약 15원이 들고, Claude 콘솔에서 웹 검색이 켜져 있어야 합니다. |
| 카카오톡 나에게 보내기 | 선택. 다 만든 카드뉴스(표지 이미지 + 캡션)를 내 카톡 '나와의 채팅'으로 받습니다. 매일 자동 초안이 생기면 알림도 옵니다. 설정 화면의 '준비 방법'대로 developers.kakao.com에 앱을 만들고 **카카오 로그인 연결**을 누릅니다. 무료입니다. |
| 매일 자동 만들기 | 프로그램이 켜져 있으면 정한 시각(기본 아침 8시)이 지난 뒤 소비자 뉴스로 초안을 만듭니다. 그 시각에 꺼져 있었으면 다음에 켤 때 만듭니다. |

키와 설정은 내 컴퓨터의 `문서\민주의 카드뉴스 제작 프로그램\config.json`에만 저장됩니다. 개발용으로 `python server.py`를 실행했다면 이 폴더의 `data/`에 저장됩니다. 둘 다 GitHub에는 올라가지 않습니다.

## 만드는 순서

1. 링크의 기사 본문을 읽습니다. 기사 사진은 가져오지 않습니다.
2. 같은 뉴스를 다룬 다른 언론사 기사 1~2개를 찾아 읽습니다. 네이버를 먼저 쓰고, 모자라면 Claude 웹 검색으로 찾습니다.
3. Claude가 원고를 씁니다. 사실만 가져오고 문장은 새로 씁니다.
4. 이미지는 힉스필드로 만듭니다. 장마다 사진·일러스트를 고르고, Claude가 쓴 장면 설명으로 힉스필드에서 만듭니다. 마지막 장은 소보루 캐릭터입니다.
5. **올리기 전 10초 체크리스트**를 코드로 검사합니다. 하나라도 걸리면 '확인 필요'로 남고, **직접 확인했어요**에 체크해 저장해야 내려받을 수 있습니다.

## 지키는 규칙

참고 자료: 「인스타 수익화 올인원 패키지 3권 · 저작권 기준표」, 「BONUS 01 캐러셀 레퍼런스북」(2026.10)

**저작권**

- 사실만 가져오고, 기사 문장은 옮기지 않습니다. 띄어쓰기를 빼고 18자 넘게 같으면 걸립니다.
- 숫자는 기사에 있는 것만 씁니다. 기사에 없는 숫자가 있으면 걸립니다.
- 기사 사진, 방송 캡처, 남의 SNS 사진은 쓰지 않습니다. 이미지는 힉스필드로 새로 만듭니다.
- AI로 만든 사진 위에는 글자를 넣지 않습니다. 'AI로 만든 이미지'라는 표시는 캡션에 직접 적습니다(체크리스트가 알려 줍니다). 직접 올린 사진은 체크리스트에서 기사 사진이 아닌지 한 번 더 확인합니다.
- 실존 인물 얼굴, 기업 로고, 유명 캐릭터는 그리지 않습니다.
- 캡션 끝에 `출처: 매체명 날짜 보도`와 링크를 붙입니다.
- 정치 뉴스는 중립적으로 다룹니다. 선거 90일 전부터 선거일까지는 정치 소재를 다루지 않는 것이 좋습니다.

**인스타 계정 키우기 (캐러셀)**

- 표지는 기사 제목이 아니라 '내 얘기로 바꾼 한 줄'에 큰 숫자 하나를 넣습니다.
- 표지 문구 후보 5개는 서로 다른 틀(경고, 변화, 쉬운 방법, 후회·경험, 원칙)로 나옵니다.
- 낚시말(충격·결국·경악)은 쓰지 않습니다. 궁금증을 만들면 본문에 반드시 답이 있어야 합니다.
- 한 장에 메시지 하나만 담고, 전체는 5~6장으로 만듭니다.
- 마지막 장은 기본이 "헷갈리면 저장해 두세요"이고, 가끔 공유형으로 바꿉니다. "댓글에 ○○ 남기면" 같은 참여 유도는 쓰지 않습니다.
- 캡션은 공감형으로 짧게 씁니다.
- 프로필 격자에서는 카드가 3:4로 잘려 보이므로, 핵심 글자는 가운데에 둡니다.

## 디자인

**프로그램 화면:** 토스처럼 회색 바탕, 흰 카드, 파란 버튼, 큰 글씨로 만들었습니다.

**카드뉴스 (뉴닉 + 소보루):**
- 구성은 뉴닉식입니다. 힉스필드 이미지를 카드 전체 배경으로 깔고, 위쪽은 크림색으로 흐리게 처리합니다. 그 위에 맨 위 작은 줄(`주제 | 한 줄 설명`), 귤색 박스 제목 두 줄, 숫자 태그를 올립니다.
- 모양은 소보루식입니다.
  - 색: 귤색 `#F7931E`, 갈색 `#652D1C`, 크림 `#FFF6E6`
  - 제목 박스: 갈색 글씨, 살짝 둥근 모서리
  - 장식: 소보루 부스러기, SOBORU 표시
  - 인사이트 장("그래서 나한테 뭐가 달라지는데?"): 갈색 바탕
  - 마지막 장: 소보루 체크리스트와 캐릭터
- 글꼴: Pretendard (SIL Open Font License, `static/fonts/Pretendard-LICENSE.txt`)

## 파일

```
server.py            화면·저장·매일 예약·사진 저장 (http://127.0.0.1:5050, 내 컴퓨터에서만 열림)
kakao.py             카카오톡 나에게 보내기 (로그인 연결·토큰 연장·표지 이미지 올리기·보내기)
cards.py             만드는 일: 기사 읽기·사실 확인·원고(Claude/붙여넣기/직접)·힉스필드 이미지·체크리스트
build.py             윈도우 exe 만들기 (PyInstaller)
templates/edit.html  카드 모양(그리기)·넘겨 보기·고치기·PNG 내려받기
static/              글꼴, 소보루 캐릭터
tests/               자동 시험 (Claude·네이버는 가짜로 바꿔 끼움)
data/                개발용 실행 때의 카드뉴스·설정 (GitHub에 안 올라감)
```

## 개발자용

```sh
python -m venv .venv && .venv\Scripts\pip install -r requirements.txt   # (맥·리눅스: .venv/bin/...)
.venv\Scripts\python -m unittest discover -s tests    # 시험
.venv\Scripts\python server.py                        # 실행 (또는 시작하기.bat)
pip install pyinstaller && python build.py            # exe 만들기 → dist\MinjuCardNews.exe
```

`cardnews/`가 바뀌어 GitHub에 올라가면 GitHub Actions(`.github/workflows/cardnews-build.yml`)가 윈도우에서 시험한 뒤 exe를 만들어 Releases의 `cardnews-latest`를 새 파일로 바꿉니다.
